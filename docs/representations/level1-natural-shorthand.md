# Representation Spec: Level 1 Natural Shorthand

Level 1 compression optimizes conversational, reasoning, and instruction text by replacing common multi-token phrases with minimal-token acronyms.

## Mappings
- `by the way` -> `btw`
- `away from keyboard` -> `afk`
- `as soon as possible` -> `asap`
- `with respect to` / `with regard to` -> `wrt`
- `in my opinion` -> `imo`
- `too long didn't read` -> `tldr`
- `for your information` -> `fyi`
- `as far as i know` -> `afaik`
- `i don't know` -> `idk`
