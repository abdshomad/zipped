# Issues Registry & Postmortems

This directory records all investigations, test failures, tokenizer discrepancies, semantic loss incidents, and performance bottlenecks.

## Issue Recording Protocol
Every issue document must strictly follow the standard 5-Section Postmortem Schema:
- **§1 Summary & Symptoms:** Observed behavior, logs, failure mode.
- **§2 Root Cause Deep Analysis:** Deterministic underlying cause.
- **§3 Exact Code & Config Changes:** File-by-file links and modifications.
- **§4 Verification & Bench-Test Evidence:** Commands and outputs demonstrating resolution.
- **§5 Preventative Safeguards:** Automated assertions, lints, or test safeguards.
